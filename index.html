完整计算逻辑说明（最终精准版）

一、基础汇率与货值

  • 汇率计算：RMB金额 ÷ 汇率 = USD金额；USD金额 × 汇率 = RMB金额。
  • 拿货总价 = 拿货单价 × 拿货个数 + 其他杂费。
  • 单个产品采购成本 = (拿货总价 + 头程总价 + 总打包费) ÷ 拿货个数。

二、头程物流成本

  • 单箱材积重 = (长×宽×高) ÷ 所填材积系数（默认6000），仅供箱规试算展示，不参与头程总价计算。箱规或材积系数异常时仅在试算区域提示，不阻断成本与利润计算。
  • 头程总价 = 单箱重量 × 总箱数 × 运输单价，不与材积重取大值。
  • 单个平摊头程 = 头程总价 ÷ 总采购数量；装箱总件数与采购数量不一致时提示核对。

三、尾程物流与仓库 (TTS/CBT/FBT)

  • 第三方本土仓：成本 = 库内操作费 + 续件费 + 包材费 + 尾程运费。
  •   - 出库费 (库内操作费)：自动根据总重量计算 (0-2LB=$0.7, 2-5LB=$1.5, 5-10LB=$2, >10LB=$2)。
  •   - 续件费：自动总额=(件数−1)×$0.3；包材费自动值为1件=0，多件=$0.3。当前件数采用可编辑的仓库费用，预览对应行同步使用；其他件数按自动费率估算。
  •   - 尾程运费：取订单实际重量与体积重(单件长×宽×高(inch)×件数÷166)的较大值匹配 TTS/CBT 价卡，超过20lb不沿用最高档低估费用。
  • FBT仓：成本 = FBT一口价(含操作与配送，内置官方价卡)。
  • 运费承担方式：
  •   - 商家包邮：商家支付全额运费。
  •   - 客户全担：客户支付全额运费。
  •   - 共同承担：客户支付阶梯运费（以实际尾程费为上限），剩余由商家支付。

四、FBT特殊政策规则

  • 体积重新规：如果一件商品的实际重量≤2磅，且其体积≤332立方英寸，则仅根据实重计算；超过任一阈值，则取Max(实重，体积重)。体积重=长×宽×高(inch)÷166(英寸)
  • 默认标准(Standard)：强制商家包邮，商家承担所有FBT费用。
  • 退出政策(Opt-Out)：
  •   - 订单金额(扣券后) ≥ $30：商家包邮。
  •   - 订单金额(扣券后) < $30：客户强制付$5.99运费，商家获得$0.75/件补贴。

五、平台费用与佣金

  • 达人佣金 = (客户最终支付金额 - 客户承担运费) × 佣金比例。
  • 平台佣金 = 客户最终支付金额 × 佣金比例。
  • 智能营销佣金 = 客户最终支付金额 × 佣金比例。
  • 货损/退货 = 客户最终支付金额 × 比例。

六、利润与ROI

  • 最终总成本 = 单件国内成本×订单件数 + 完整仓配费用 − FBT补贴 + 平台佣金 + 智能营销佣金 + 达人佣金 + 货损。客户运费计入收入，故成本保留完整物流费，不重复抵扣。
  • 实际收入 = 客户最终支付总额 (含客户运费)。
  • 最终利润 = 实际收入 - 最终总成本。
  • 保本ROI = 最终利润 > 0 ? (实际收入 ÷ 最终利润) : 无法保本；不代表已发生广告花费的实际投产。
  • 优惠券不超过商品总额；主面板与预览采用同一订单计算函数。全部金额保留原始精度计算，仅显示时保留两位小数。

七、达人寄样成本

  • 本土仓寄样 = (单品采购头程成本 + 库内操作费 + 包材费 + 尾程运费) × 寄样数量。
  • FBT仓寄样 = (单品采购头程成本 + 单件订单FBT配送费) × 寄样数量，不随当前销售订单件数变化，不抵扣销售补贴。
  • 回本单量 = 寄样总成本 ÷ 单单利润 (向上取整)。

八、需回本销售件数测算

  • 国内成本统计 (采购+头程+杂费）总费用 = (拿货总价 + 头程总价 + 总打包费) ÷ 汇率。
  • 单件现金贡献 = (订单实际收入 − 完整仓配费用 − 佣金及货损 + FBT补贴) ÷ 订单件数；盈利或亏损采用同一口径，国内采购头程成本只在总投入中扣一次。
  • 需回本销售件数 = 向上取整(总投入 ÷ 单件现金贡献)；贡献非正时无法回本，所需件数超过库存时提示库存不足。
  • 回本后剩余可售件数 = Max(0，拿货个数 − 需回本销售件数)。
  • 整批库存售完预计利润 = 拿货个数 × 单件现金贡献 − 总投入。
  • 现阶段最终盈亏 = 现已售卖件数 × 单件现金贡献 − 总投入；不提前将贡献四舍五入。
